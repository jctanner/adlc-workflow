# Public artifacts

This directory contains validator-facing and publishable evidence generated by
an ADLC run. It must not contain private workflow state, credentials, locks, or
effect intents. The active profile is authoritative for the exact names and
locations; the paths below describe the feature creator profile.

The runtime creates these top-level files when applicable:

- `rhai-feature-selection.json` — frozen membership, ordering, and exclusion evidence.
- `rhai-feature-result.json` — terminal aggregate result and completion status.
- `rhai-feature-pipeline-data.json` — normalized downstream data projection.

The category directories contain per-ticket or per-run outputs:

- `rhai-feature-inputs/` — normalized captured inputs and completeness metadata.
- `rhai-feature-originals/` — immutable source snapshots and comments.
- `rhai-feature-tasks/` — accepted generated documents and task-facing outputs.
- `rhai-feature-reviews/` — base review and concern findings.
- `rhai-feature-extension-results/` — plugin activation, generated values, and
  findings.
- `rhai-feature-reports/` — human- and dashboard-facing aggregate reports.
- `rhai-feature-published/` — publication-ready copies and manifests.

Operational state belongs under `.adlc/state/`, not here.
